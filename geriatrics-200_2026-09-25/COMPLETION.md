## Checks run

- Selection: editor, then an independent checker; 70 swaps from the mechanical ranking; delirium excluded; earlier collection compared (digest in _working/earlier_collection).
- Evidence: every candidate researched and each claim recorded with a verbatim supporting passage and access level.
- Fact-check: an independent agent re-opened sources for every category and listed blocker, major and minor issues with replacement wording; all blockers and majors were applied. Several categories had blockers (for example C06 3, C07 4, C08 1).
- Plain-English cold read with known-bad controls (C01 controls failed as intended). For C02 and C04 the same agent read and fixed, and the after-fix scores are estimates.
- Deterministic checker over all captions, alt text and visual text: no em dashes, exclamation marks or first-person clinical claims; Bluesky 226 to 300 characters, Threads 353 to 500, X 571 to 1,382, LinkedIn 935 to 2,385. Remaining flags are justified (VITAL trial name, literal 'sits in', tick and arrow glyphs on charts).
- Duplication against the earlier 200 posts: 3 posts share a few five-word sequences with an earlier post; no repeated openings within the new set.
- Visual inspection: no independent visual inspection pass was run (the pilot that would have done so was stopped to save tokens). Every visual had one designer pass with a clean automatic layout report (nothing outside the card, no clipped text, text 22 px or larger) and a read-back of the rendered text; a random 12-image sample was reviewed by eye and found sound. Spot-checking the rest is recommended.
